# HEXMovr OpenArm Documentation

Docusaurus documentation site for the HEXMovr motor-adapted OpenArm platform.

## Requirements

- Node.js 20+
- npm

## Local development

```bash
npm install
npm run start
```

## Production build

```bash
npm run build
npm run serve
```

## GitHub Pages

Set the `url`, `baseUrl`, `organizationName` and `projectName` in `docusaurus.config.ts` to match the actual deployment repository before enabling GitHub Pages.

## Content policy

Replace all production `TBD` fields with verified hardware and software specifications. Do not publish proprietary CAD/BOM/protocol material unless the project owner has confirmed it is releasable.
