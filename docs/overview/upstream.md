# Upstream OpenArm

HEXMovr OpenArm is based on the architecture and public software ecosystem of OpenArm.

Useful upstream resources:

- OpenArm documentation: https://docs.openarm.dev/
- Main repository: https://github.com/enactic/openarm
- OpenArm CAN library: https://github.com/enactic/openarm_can
- OpenArm hardware repository: https://github.com/enactic/openarm_hardware

The upstream repository currently lists separate repositories for hardware, robot description, CAN control, ROS 2, teleoperation, Isaac Lab, MuJoCo, datasets and Dora integration.

The upstream `openarm_can` project is a low-level CAN control library and currently documents C++ and experimental Python interfaces.
