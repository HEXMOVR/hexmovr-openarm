# Single Motor Test

1. Lift the mechanical load or secure the joint.
2. Connect only one motor if possible.
3. Verify CAN termination.
4. Bring up `can0`.
5. Discover/read the motor.
6. Enable the motor.
7. Send a very small position command.
8. Check feedback.
9. Disable the motor.

Record the exact:

- motor model;
- firmware version;
- CAN ID;
- bitrate;
- command;
- response;
- fault state.
