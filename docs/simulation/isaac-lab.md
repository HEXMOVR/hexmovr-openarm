# Isaac Lab

The Isaac Lab integration should provide:

- robot asset;
- joint mapping;
- actuator model;
- observation/action definitions;
- reset state;
- control frequency;
- domain randomization configuration.

Keep the simulation actuator abstraction aligned with the physical HEXMovr control interface so policies can be transferred with fewer hidden assumptions.
