# ZE300 GUI 上位机

当前资料中的 ZE300_GUI 软件用于通过 RS485 自定义通信协议连接产品，并提供实时信息、用户参数、运动控制和固件更新等功能。

## 1. 串口连接

资料给出的默认值：

| 项目 | 默认/说明 |
| --- | --- |
| 通信方式 | RS485 |
| USB 接口 | 若产品不含 USB，需要 USB 转 485 |
| 默认设备地址 | `1` |
| 默认 RS485 波特率 | `115200` |
| 公共地址 | `255` |

连接产品并供电后，设置通信参数并点击 `Connect`。

> 电机/驱动板的 CAN 通信与 ZE300 GUI 的 RS485 连接是两个不同的通信入口。CAN 协议请参阅 [HEXMovr CAN Protocol](../api-reference/motor-protocol)。

## 2. 版本信息

软件可以显示：

- 应用软件版本；
- 硬件型号；
- RS485 协议版本；
- CAN 协议版本；
- Boot 版本；
- UID。

## 3. 实时信息

资料列出的实时信息包括：

- 单圈绝对值角度；
- 多圈绝对值角度；
- 旋转速度；
- Q 轴电流；
- 母线电压；
- 母线电流；
- 工作温度；
- 运行状态；
- 电机使能/失能状态；
- 故障码。

资料说明电机一圈的 Count 值为 **16384**。Q 轴电流与力矩的关系为：

```text
Torque = Q-axis current × torque constant
```

## 4. 用户参数

资料中包括：

- 编码器型号；
- 编码器方向；
- 第二编码器使能；
- 速度滤波系数；
- 设备地址；
- RS485 波特率；
- CAN 波特率；
- 最大电压/电流/温度阈值；
- 电压/电流/温度故障持续时间；
- 电流环带宽；
- 电角度偏移；
- 机械角度偏移；
- UVW 相电流偏移；
- 读取；
- 写入并保存。

## 5. 运动控制

资料描述了：

- 位置环 / 速度环 PID；
- MIT 控制参数；
- Q 轴电流控制；
- 速度控制；
- 绝对值位置控制；
- 相对位置控制。

其中 MIT 控制可设置目标位置、速度前馈、Kp、Kd 和力矩前馈，实现力位混合控制。

## 6. 控制命令

资料列出：

- 参数恢复默认值；
- 编码器角度校准；
- 设置当前位置为原点；
- 最短距离回原点；
- 清除当前故障；
- 系统重启；
- 电机失能（OFF）。

### 编码器角度校准

编码器校准要求系统处于空闲状态。校准过程中电机将正反旋转约 **30–90 秒**，期间应确保电机空载并且不干扰电机运动。

### 电机失能

资料说明，点击 OFF 可以关闭电机输出；电机进入失能/自由状态。异常或紧急情况下，应结合整机安全设计使用可靠的断电/急停措施。

## 7. 固件更新

资料说明最新固件可联系销售获取，并按软件界面提示进行更新。固件更新过程中，实时运动信息和实时状态信息不会刷新。
