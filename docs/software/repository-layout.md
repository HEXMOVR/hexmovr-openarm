# Repository Layout

A clean product-oriented organization is:

```text
hexmovr-openarm/
├── README.md
├── LICENSE
├── NOTICE
├── website/
├── openarm_description/
├── hexmovr_can/
├── hexmovr_ros2/
├── hexmovr_teleop/
├── hexmovr_mujoco/
└── hexmovr_isaac_lab/
```

Keep the upstream-derived repositories and HEXMovr-owned adaptations visibly separated in commit history and documentation.
