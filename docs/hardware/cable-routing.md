# 线材长度与插接方向

以下为当前 OpenArm 装配材料中整理的线材长度、端子类型和插接方向。

| 连接关系 | 长度 | 端子类型 | 特殊处理 |
| --- | ---: | --- | --- |
| 集线板 → M1 | 20 cm | 公转母头 XT30 + PHD2×2 | 双头直插 |
| 集线板 → M2 | 40 cm | 公转母头 XT30 + PHD2×2 | 双头直插 |
| 集线板 → M3 | 40 cm | XT30（2+2） | 弯头转直插 |
| M3 → M4 | 15 cm | XT30（2+2） | 双头同向折弯 90° |
| M4 → M5 | 10 cm | XT30（2+2） | 双头同向折弯 90° |
| M5 → M6 | 15 cm | XT30（2+2） | 双头同向折弯 90° |
| M6 → M7 | 10 cm | XT30（2+2） | 双头同向折弯 90° |
| M7 → M8 | 10 cm | XT30（2+2） | 双头同向折弯 90° |

## 连接关系

```text
集线板
├── M1
├── M2
└── M3
     └── M4
          └── M5
               └── M6
                    └── M7
                         └── M8
```

## 插接方向

- 集线板 → M1：双头直插；
- 集线板 → M2：双头直插；
- 集线板 → M3：弯头 → 直插；
- M3 → M4：双头同向折弯 90°；
- M4 → M5：双头同向折弯 90°；
- M5 → M6：双头同向折弯 90°；
- M6 → M7：双头同向折弯 90°；
- M7 → M8：双头同向折弯 90°。

> **装配注意：** 线材长度及连接器方向应按照上表选择和安装。若机械结构或电机版本发生变化，应重新核对实际干涉和弯曲半径。
